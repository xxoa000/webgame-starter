# 게임 전용 오디오

외부 음원이나 샘플 없이 이 프로젝트용으로 합성한 오리지널 신스 음원이다.
모든 WAV는 모노 22,050Hz / 16-bit PCM이며 별도 오디오 라이브러리나 외부 서비스가 필요 없다.

- `control-room.wav`: 관제실·캐릭터·게시판·상점의 32초 배경음 루프
- `exploration.wav`: 탐색 페이지의 32초 배경음 루프
- `click.wav`: 활성 버튼·링크 클릭
- `encounter.wav`: 몬스터 조우
- `attack.wav`: 일반 전투·레이드 공격
- `damage.wav`: 피격
- `victory.wav`: 일반 전투·레이드 승리 및 설정의 효과음 미리 듣기
- `flee.wav`: 일반 전투 도망

재생은 첫 사용자 동작 이후 시작한다. 탐색 페이지 진입·이탈 시 배경음을 0.5초에 걸쳐 전환하고,
숨겨진 탭에서는 오디오를 일시정지한다. `bureau.audio.v1` localStorage 키에 배경음·효과음 볼륨을
각각 저장하며, 어느 한쪽을 0%로 내려도 다른 쪽은 유지된다.

음원을 교체할 때는 같은 파일명과 경로를 유지한다. 루프 파일은 시작과 끝이 자연스럽게 이어지도록 준비한다.
원음을 다시 생성하려면 저장소 최상위에서 다음 명령을 실행한다.

```bash
python3 frontend/scripts/generateAudio.py
```
